## ❓ 这个项目是什么

《辽宁省实验生存指南》是由在校生及已毕业校友合作贡献编写的手册，期望以**学生的视角**记录值得一提的事情。

每一小节由不同同学贡献而成，但尽可能将各种观点统一在手册的框架下 —— 这样做的目的是汇聚更多可供参考的意见。

## ❌ 这个项目不是什么

### 不是学校官方指南

本手册 **并非** 学校官方所作。恰恰相反，本手册是为了补充因视角不同而导致学校官方在传达部分消息方面的不足。

正因如此，本手册由民间自发建立，且不会也不愿受到官方过多的干涉。

### 不是高考生活攻略

高中生活，或者更广泛地说，人生，并没有一个模板。所谓「攻略」所给出的生活看似美好，但可能并不适合自己。比起盲从他人，明确自己的目标并以此规划生活则更为重要。

正因如此，本手册的定位是「参考」与「建议」，而不是「规则」。

### 不是内容的唯一来源

手册中部分内容摘抄自其他学校的成型内容（如 [上海交通大学生存手册](https://survivesjtu.gitbook.io/survivesjtumanual)、[上海交通大学大学飞跃手册](https://survivesjtu.github.io/SJTU-Ap)、[南方科技大学飞跃手册](https://sustech-application.github.io/2019-Fall/#/)、[东北师大附中生存手册](https://ziyou-qinghua.github.io/)），多数文章已标注出处。使用这些内容遵循其原始许可。

## 🛠️ 本地开发

文档站基于 VitePress，需要 [Node.js](https://nodejs.org/) 18+。

```bash
# 安装依赖
npm install

# 启动本地开发服务器（默认 http://localhost:5173）
npm run docs:dev

# 构建静态站点到 docs/.vitepress/dist
npm run docs:build

# 预览构建结果
npm run docs:preview
```

站点通过 GitHub Actions 自动部署到 GitHub Pages，配置见 [`.github/workflows`](https://github.com/Jiboyu78/SurviveLNSY/tree/main/.github/workflows)。

### 目录结构

```
SurviveLNSY/
├── docs/
```

## ✍️ 参与贡献

欢迎所有在读同学与校友投稿。

1. 在 `docs/` 下对应板块新建 Markdown 文件
2. 在 [`docs/SUMMARY.md`](https://github.com/Jiboyu78/SurviveLNSY/blob/main/docs/SUMMARY.md) 中登记条目 —— **不登记不会出现在侧边栏**

### 写作约定

- 使用 **Markdown**，图片放在 `docs/public/` 下
- 标题层级从 `##` 开始（`#` 保留给板块名）
- 注明内容出处，尤其是摘抄自其他手册的部分
- 保持「中立」「公益」，不接受任何形式的商业支持
