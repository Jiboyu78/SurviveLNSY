# 食堂

辽宁省实验中学拥有三层楼豪华食堂。每日两次的千人大竞走也是固定的校园景观。食堂里也不允许带手机！可能被主任随机抓捕。
一楼为“盒饭”，每周会在学校公众号发菜谱，定价标准为2荤1素15元，1荤两素13元，1素3元。汤、米饭免费不限量，中午去得早还可以在饭桶旁边的铁盘里抢到馒头，素菜随便添，需要注意3元套餐的素菜在原则上是指定的，不允许挑选。实际的给饭情况随打饭的大爷大姨而不同，有的比较善良的大姨可能会在监督者不在的时候偷偷多给一点肉，也可能允许饭量小的你花11元买1荤1素，也可能默许你自选3元的素菜，但这些恩惠是不可奢望的，如果他们施与你这些恩惠被领导发现，他们就会面临批评，甚至处罚。如果你饭量比较大而懒得排队添菜，想在第一次多要一些，可以直接提出，一般大爷大姨都会给你。
非新疆学生，早餐只有一楼。
一楼邪修吃饭方法：
零元套餐：在2026年上半年，学校提供的免费汤还是超多淀粉的菠菜汤，随机刷新黄瓜西红柿汤、紫菜汤。这时就有各路捞汤大神各显神通，将“轻捞慢起，勺子衬底”的秘诀发挥到极致，这一勺捞上来就是一道菜。但是目前貌似换成了NEYC同款绿豆汤，想捞到丰厚的汤底只有等水被捞得所剩无几了才行，而且绿豆非常干，难以下饭。于是零元套餐这一秘籍失去了实用价值。
顽童戏老叟：省实验最邪修的吃饭方法，由于饭吃完了没人知道你点的什么菜，只要先点一次三元套餐，迅速吃完，等人走的差不多了去添饭，就能够添到巨量的菜。尤其是在马上要散场的时候（这大概发生在高一开始吃饭之后的15分钟到25分钟），大爷大妈们不得不把盛菜的盘子里面的菜都倒进垃圾桶（这些剩菜要被学校统一处理），而大爷大妈们自己装绝对是装不了多少的，看着这么多的菜被浪费，谁都会非常心疼，因此你只要在这个时候去添菜，别说是素菜能够随便添、要多少有多少了，就是肉菜，如果你遇到比较善良的，也可能获得一些。
tip：如果你临时遇到汤洒到身上、地上等意外情况，一楼水吧、二楼配料桌上都可以拿到纸巾，一楼、二楼的西北角有拖布。
二楼也有盒饭，但是不如一楼好，个人不建议在二楼吃盒饭。非新疆学生不要去西北风味窗口，西北风味窗口不收费，还有酸奶，如果冒充新疆生被发现会被制裁。
二楼菜品会偶尔上新，可以关注一下。
三楼是座位最少的楼层，因此从三楼买饭然后到一楼或二楼找座位是非常常见的，只是强迫症送空盘子会麻烦些。小卖部不卖德萨克之后，三楼的汉堡就是省实验唯一的正经汉堡（
三楼的右边是老师的午餐、晚餐用餐区，老师餐区有酸奶、大麦茶、馒头，此外所有菜和学生盒饭相同，只不过是自助。夏天有西瓜，但是有专人看守，想偷摸去拿恐怕是无法成功了。（老师的早餐是在总务处旁边的美食苑）
