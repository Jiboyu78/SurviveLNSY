# 小卖部

省实验小卖部绝对是最热门的去处了。小卖部塑料袋收费。实验杯期间等热点时期，第四节课间小卖部经常被挤爆，即使高一有20分钟课间也无法完成排队，小卖部贴心提供预定服务，持饭卡预定，第四节课间到小卖部直接取，爽爆。一定不要错过冰柜和冰箱里的东西，夏日肝作业神器——冰杯，配一瓶任意饮料都很爽。小卖部的货品依然是不定期上新，欢迎大家推荐震撼美味。最值得说的也许是泡面，一定要注意泡面分汤面和拌面，汤面是先放料再泡热水，拌面是先泡热水，泡熟面之后把水倒掉再加料。
老吃家传授拌面秘诀：倒热水的时候用盒盖上的小孔太慢了，直接掀盖拿叉子抵住面饼就可以完美倒水。然后把面饼先豁松开，再加料，直接扣盖，两手拇指、小指上下夹住，三指握住面盒，前后摇晃即可完美拌匀。注意摇面这一步一定要双手，单手会让面起飞。
